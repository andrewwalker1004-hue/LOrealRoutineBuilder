## Prompt Writing

My system prompt does three jobs. First, it sets a persona: a warm, expert advisor for the L'Oréal family of brands. Second, it gives the model the data it needs. I rebuild the prompt on every request so it always contains the user's *current* selected products as JSON (name, brand, category, description). That way, if someone adds or removes a product mid-conversation, the AI knows right away. Third, it sets rules: order steps correctly (cleanse → treat → moisturize → SPF), split AM and PM, explain why each product is there, flag conflicts like retinol plus benzoyl peroxide, stay on beauty topics, never diagnose, cite sources when searching, and reply in the user's language.

The biggest lesson was that being specific beats being long. "Make a routine" gave generic advice. "Use ONLY these products, order them AM/PM, and explain each step" gave useful answers.

## Overcoming Roadblocks

*(Replace this with your own story. Some options:)*
- **CORS errors** when calling the Worker. I fixed them by handling the `OPTIONS` preflight and returning `Access-Control-Allow-*` headers on every response.
- **`products.json` not loading** when I opened `index.html` directly. `fetch` needs a server, so I used Live Server.
- **Follow-ups forgot context.** I learned that the API is stateless, so I keep a `conversation` array and send the whole history each time.
- **Selections persisting.** I needed to store IDs (not whole objects) in `localStorage` and re-render both the cards and the selected list on load.
